# 重組 DNA 技術 · 一步一步看懂

香港 DSE 生物科互動教學：限制酶切割與重組質粒的形成。全頁繁體中文，無需登入、網絡字型、後端或外部服務。

主畫面參照課本圖示層次重新繪製：紅色目標基因、綠色環狀質粒、紫色末端及黑色箭頭。以「限制酶甲／乙」稱呼兩種示範酶，學生無需記憶專名；實際序列與切割位置不變。每步只處理一個概念，比較、短題、方向提示及延伸內容預設收起。

新增拼圖形狀示意：用三角形與弧形的突出／凹入部分分別代表 A–T、C–G，兩個接合處均從實際鹼基配對資料生成。這是鹼基互補的比喻，不是 DNA 切口的實際外形。相容時拼圖暫時吻合，加入連接酶後才顯示固定骨架；不相容時指出不吻合的鹼基。真正序列與切口可展開對照，成功判斷仍依兩端是否互補，不依酶名稱或拼圖種類。

## 學習流程

1. 認識目標 DNA 與質粒。選擇「相同限制酶」或「本例的不同限制酶」並作預測；另可展開選項，分別選擇甲／乙。更換時載入含相應限制位點的模擬序列。
2. 按「用限制酶切割」，觀察目標基因兩側與環狀質粒的切割。放大圖以接近課本的階梯形 DNA 末端，顯示錯開的骨架切口與四鹼基黏端。
3. 拖動目標片段至質粒，或使用「嘗試配對」／鍵盤 Enter。兩個接合處均檢查實際方向排列的鹼基。
4. 加入 DNA 連接酶，觀察氫鍵配對與骨架共價連接的分別。

下方的兩情境比較、延伸思考、三題可重試短題及自由解釋題均預設收起，可按需要展開。答案只留在目前頁面，不會上傳。支援減少動畫、暫停／繼續、上一步、重播與重設。

## 科學模型

- 限制酶甲（程式內部使用 HindIII）：`5′ A|AGCTT 3′` / `3′ TTCGA|A 5′`，5′ 突出黏端 AGCT。
- 限制酶乙（程式內部使用 EcoRI）：`5′ G|AATTC 3′` / `3′ CTTAA|G 5′`，5′ 突出黏端 AATT。
- 上鏈在第 1 個鹼基後切割，下鏈在第 5 個鹼基後切割；骨架切口位於相鄰核苷酸之間。
- 接合處 1 取質粒左端與插入片段左端；接合處 2 取插入片段右端與質粒右端。兩端均逐一依 A–T、C–G 判斷，不使用酶名稱作成功判斷。
- 配對階段仍有四個骨架切口；連接酶作用後才以共價鍵連接。
- 模擬序列不是胰島素基因序列；重組質粒形成不代表已完成細菌轉化或蛋白質生產。

## 自動驗收

網頁本身無需安裝套件。開發驗收需要 Node.js 及 Chromium：

```sh
npm ci
npx playwright install chromium
npm test
```

若系統已有 `/usr/bin/chromium`，不必下載瀏覽器；也可設定 `CHROMIUM_PATH`。`TEST_URL` 可指定另一預覽網址，預設自動啟動暫時的本機伺服器，測試後關閉。

驗收包括：真實序列互補及黏端長度、兩個接合處、連接前後骨架切口、HindIII／EcoRI 不相容、375／768／1280 像素版面、無水平溢出、拖動、鍵盤、暫停／繼續、情境切換、返回、重播、重設、短題重試及瀏覽器錯誤。截圖儲存於系統暫存資料夾 `restriction-enzyme-checks`。
