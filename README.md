# 基因接合實驗室

香港 DSE 生物科互動教學：限制酶切割與重組質粒的形成。全頁繁體中文，無需登入、網絡字型、後端或外部服務。

## 直接使用／預覽

下載 `index.html`，用 Chrome、Edge、Firefox 或 Safari 開啟，即可完整操作。所有樣式、圖示及程式均在同一檔案內，離線亦可使用。

也可在專案目錄執行 `python3 -m http.server 8000`，再由同一電腦的瀏覽器開啟 `http://localhost:8000`。

## 發布至 GitHub Pages

在本儲存庫的 **Settings → Pages → Build and deployment** 選擇 **Deploy from a branch**，分支選 **main**，資料夾選 **/(root)**，按 **Save**。部署完成後網址為：

https://lycheey1126-png.github.io/restriction-enzyme/

此網址須待上述 Pages 設定及部署完成後才可使用。

## 學習流程

1. 選擇情境及預測。選項變更時會載入含相應限制位點的模擬序列。
2. 觀察目標基因兩側與環狀質粒的切割，放大圖顯示錯開的骨架切口與四鹼基黏端。
3. 拖動目標片段至質粒，或使用「嘗試配對」／鍵盤 Enter。兩個接合處均檢查實際方向排列的鹼基。
4. 加入 DNA 連接酶，觀察氫鍵配對與骨架共價連接的分別。

下方另設兩情境比較、預設收起的延伸思考、三題可重試短題及自由解釋題。答案只留在目前頁面，不會上傳。支援減少動畫、暫停／繼續、上一步、重播與重設。

## 科學模型

- HindIII：`5′ A|AGCTT 3′` / `3′ TTCGA|A 5′`，5′ 突出黏端 AGCT。
- EcoRI：`5′ G|AATTC 3′` / `3′ CTTAA|G 5′`，5′ 突出黏端 AATT。
- 上鏈在第 1 個鹼基後切割，下鏈在第 5 個鹼基後切割；骨架切口位於相鄰核苷酸之間。
- 接合處 1 取質粒左端與插入片段左端；接合處 2 取插入片段右端與質粒右端。兩端均逐一依 A–T、C–G 判斷，不使用酶名稱作成功判斷。
- 配對階段仍有四個骨架切口；連接酶作用後才以共價鍵連接。
- 模擬序列不是胰島素基因序列；重組質粒形成不代表已完成細菌轉化或蛋白質生產。

## 自動驗收

網頁本身無需安裝套件。開發驗收需要 Node.js 及 Chromium：

```sh
npm ci
npx playwright install chromium
npm test
```

若系統已有 `/usr/bin/chromium`，不必下載瀏覽器；也可設定 `CHROMIUM_PATH`。`TEST_URL` 可指定另一預覽網址，預設自動啟動暫時的本機伺服器，測試後關閉。

驗收包括：真實序列互補及黏端長度、兩個接合處、連接前後骨架切口、HindIII／EcoRI 不相容、375／768／1280 像素版面、無水平溢出、拖動、鍵盤、暫停／繼續、情境切換、返回、重播、重設、短題重試及瀏覽器錯誤。截圖儲存於系統暫存資料夾 `restriction-enzyme-checks`。
